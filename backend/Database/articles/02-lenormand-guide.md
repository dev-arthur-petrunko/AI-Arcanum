Ленорман не читають по одній карті. Базова одиниця — **пара**: перша карта — тема,
друга — уточнення. Вершник + Лист = швидка звістка; Хмари + Сонце = труднощі минають.

**Тріада** (три карти поспіль) — минуле / теперішнє / майбутнє або
підмет / дієслово / додаток: «Хто — що робить — з чим». Серце + Кільце + Дім =
любовний союз веде до спільного дому.

Головне правило: сусідні карти фарбують одна одну. Вчи значення 36 карт
напамʼять (є квіз на сайті) — і розклади складуться самі.
