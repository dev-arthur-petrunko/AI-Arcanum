# Аудит колод — звірка кількості (оновлено 2026-09-14)

Метод: скрипт звіряє кожну колоду з еталонним списком номерів
(старші аркани `0,I..XXI`, молодші `{Wands,Cups,Swords,Pentacles}-{01..14}`,
Ленорман `1..36`, І-Цзин `1..64`, поема `1..29`, Футарк `1..24`, Місяць `1..8`,
МАК `1..12`, COPE `B,A,S,I,C,P`, Астро `1..26`, Шамани `1..12`, Циганські `1..36`,
Гральні `{H,D,C,S}-{A,K,Q,J,10,9,8,7,6}`, Цолькин `S01..S20+T01..T13`,
Предки `1..12`, Нумерологія `1..9,11,22,33`).
Перевіряються: кількість, пропущені номери, дублі `(deck_id, number)`,
порожні назви, відсутність `image_path`, а також поле `Deck.card_count` vs факт.
