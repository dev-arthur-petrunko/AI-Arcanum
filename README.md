# ✦ AI-Arcanum — живая энциклопедия гадательных карт

> Интерактивная 3D-энциклопедия Таро, Ленорман, І-Цзин, рун и оракулов.
> Погружение в мир символов — с процедурной графикой, раскладами и гайдами, на трёх языках: **UK · RU · EN**.

---

## Что это

**AI-Arcanum** — учебный и справочный проект, в котором карты **не сканы, не фото**, а **процедурно сгенерированные произведения**: каждый аркан собирается кодом (Python + Pillow), а передается через интерактивную **3D-витрину** с переворотом карт, свечением и частицами.

Вся база — суверенное наследие и собственный исследовательский пересказ: **33 эзотерические системы**, классические и авторские колоды, подробные разборы значений.

## Возможности

- **Более 900 карт** в 38 колодах и 33 системах — каждую можно перевернуть в 3D, посмотреть изображение и полный разбор значения.
- **8 направлений-категорий**: гадание, оракулы, терапевтика, астрология, шаманизм, календари, эзотерика, нумерология.
- **3D-витрина** (React Three Fiber): веер карт, луна, стол с золотыми кольцами, звёзды, bloom и виньетка.
- **Полный разбор карты**: перевод, ключевые значения (прямое и перевёрнутое), темы, символы, карта дня.
- **Расклады**, карта дня, случайная карта колоды, прямой вход через `?card=`.
- **Три языка интерфейса и содержания** — переключение в один клик.
- **Тёмная (ночное золото) и светлая (пергамент) темы**.
- **45 статей и гайдов**, глоссарий, таймлайн истории карт, флеш-квиз.
- Полнотекстовый поиск по базе (SQLite FTS5).

## Технологии

| Слой | Стек |
|---|---|
| Frontend | **Next.js 14** (App Router) · React 18 · React Three Fiber · GSAP · Lenis |
| Backend | **FastAPI** · SQLAlchemy · SQLite (100% Python) |
| Графика | процедурная генерация карт на **Pillow** |
| Стили | чистый CSS, дизайн-система «Ночное золото», без UI-фреймворков |

### API

`/systems` · `/decks` · `/cards` (+ `?deck_id`, `?lang`, поиск) · `/cards/random` · `/cards/daily` · `/search` (FTS5) · `/spreads` · `/glossary` · `/timeline` · `/stats` · `/articles` · `/quiz/*`

Интерактивные Swagger-доки — на `http://localhost:8001/docs`.

## Маршруты сайта

| Маршрут | Что это |
|---|---|
| `/` | Главная: живой счётчик систем/колод/карт, карта дня, направления |
| `/directions/{slug}` | 8 направлений: все карты колод направления сразу, сгруппированные по колодам |
| `/directions/{slug}/spreads` · `/guides` | Расклады и гайды направления |
| `/decks/{id}` | Страница колоды: значения карт (по мастям) и 3D-витрина |
| `/spreads` | Каталог схем раскладов + онлайн-расклад |
| `/articles` | 45 статей на трёх языках |
| `/history` · `/glossary` · `/quiz` | Таймлайн, глоссарий, флеш-квиз |

## Быстрый старт

### Backend (`http://localhost:8001`)

```powershell
cd backend
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python scripts/seed_db.py
uvicorn app.main:app --reload --port 8001
```

### Frontend (`http://localhost:3000`)

```powershell
cd frontend
npm install
npm run dev -- -p 3000
```

Запросы `/api/*` проксируются на backend в `next.config.js`.
