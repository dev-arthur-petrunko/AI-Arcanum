## 1. Бекенд — 100% Python (перевірено: 30 .py-файлів, 0 рядків іншою мовою)

| Шар | Технології | Навіщо |
|---|---|---|
| API | FastAPI 0.115 + Uvicorn | REST, автодоки `/docs`, CORS для фронту |
| ORM | SQLAlchemy 2.0 (типізований `Mapped`) | моделі, звʼязки, каскади |
| БД | SQLite → (план) PostgreSQL + Alembic | файл `backend/Database/fortune_cards.db` |
| Схеми | Pydantic v2 | `CardOut`, `ArticleOut`, `QuizAnswerIn`… |
| Пошук | SQLite FTS5 (`cards_fts` + тригер + rebuild) з LIKE-фолбеком | `/search` + фільтри |
| Картинки | Pillow | превʼю/стиснення для вебу |
| HTTP-клієнт | requests + BeautifulSoup4 | PD-імпортери |

`System` → `Deck` → `Card`; `CardCorrespondence` (аналоги між системами);

## 7. Порожні секції 14.09 — причина і фікс
Симптом: SSR віддає цифри, а секції в браузері порожні (фолбек-віяло, «Обери карту…»).
Причина: `cmd set NEXT_PUBLIC_API_URL=... &&` дописував пробіл у значення —
бандл містив `"http://localhost:8001 "` → `fetch()` кидав на кожному запиті.
Фікс (клас проблеми прибрано повністю): same-origin проксі `next.config.js`
(`/api/:path*` → `127.0.0.1:8001`), `lib/api.js` у браузері ходить у `/api`,
CORS більше не потрібен для фронту. Перевірено всі 8 викликів браузера через проксі.
